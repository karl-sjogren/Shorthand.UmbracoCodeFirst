# UCF109: Incompatible Umbraco property editor type

The CLR property type does not match the return type documented for the referenced editor. Check
the property declaration and Data Type editor alias. Nullable values and documented collection
shapes are accepted; picker and configuration-dependent editors use conservative compatibility
rules.

For a Media Picker, use `MediaWithCrops` for single selection or
`IEnumerable<MediaWithCrops>` for multiple selection. The corresponding documented
`IPublishedContent` shapes are also accepted. When multiplicity cannot be determined statically,
either media shape is accepted. Built-in Data Type configuration can change outside Code First, so
its multiplicity is not assumed. See [Media Picker configuration](../property-editors.md#media-picker).
