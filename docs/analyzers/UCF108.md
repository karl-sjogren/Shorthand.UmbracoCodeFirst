# UCF108: Unknown Umbraco property editor

The Data Type references an editor schema alias that is not present in the repository's built-in
editor metadata catalog. Check the alias against the current Umbraco documentation or add a
supported catalog entry before synchronizing the Data Type.

```csharp
// UCF108: the schema alias is misspelled.
[UCFDataType("Title", "Umbraco.TextBok", "Umb.PropertyEditorUi.TextBox")]
public partial class TitleDataType;
```

```csharp
// Use a known schema alias (or the generated editor type).
[UCFDataType("Title", typeof(UmbracoEditors.TextBox))]
public partial class TitleDataType;
```

These snippets use `Shorthand.UmbracoCodeFirst.Attributes` and
`Shorthand.UmbracoCodeFirst.PropertyEditors`.
