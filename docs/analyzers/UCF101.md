# UCF101: Code-first aliases should be unique within their scope

| Property | Value |
| -------- | ----- |
| Id       | UCF101 |
| Category | CodeFirst |
| Severity | Warning |
| Code fix | No |

## Example

### Code with Diagnostic

```csharp
[UCFDocumentType("product", "Product")]
public partial class ProductPage;

[UCFDataType("Product editor", "Umbraco.TextBox", "Umb.PropertyEditorUi.TextBox", Alias = "product")]
public partial class ProductEditor;
```

### Code without Diagnostic

```csharp
[UCFDocumentType("product", "Product")]
public partial class ProductPage;

[UCFDataType("Product editor", "Umbraco.TextBox", "Umb.PropertyEditorUi.TextBox", Alias = "productEditor")]
public partial class ProductEditor;
```

## Remarks

The analyzer checks definition aliases globally and property aliases within their containing
Document Type. For compositions, it also checks the effective composition graph: a shared
composition can be reused by multiple Document Types, but a property alias conflict between the
main type and a composition (or between composition branches) is reported. It also reports
conflicting aliases used by layout attributes in the same Document Type.
