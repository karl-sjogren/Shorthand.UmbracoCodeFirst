# UCF119: Default template must be allowed

| Property | Value |
| -------- | ----- |
| Id | UCF119 |
| Category | CodeFirst |
| Severity | Error |
| Code fix | No |

When `DefaultTemplateAlias` is set on a document type, include that template in
`AllowedTemplateAliases`:

```csharp
[UCFDocument("Landing page",
    DefaultTemplateAlias = "landingPage",
    AllowedTemplateAliases = new[] { "landingPage" })]
public partial class LandingPage;
```

The analyzer compares aliases case-insensitively to avoid false positives when
Umbraco resolves differently cased aliases to the same template. It does not check
whether the template exists; synchronization validates that at runtime.
