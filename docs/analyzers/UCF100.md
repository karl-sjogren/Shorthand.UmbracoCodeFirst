# UCF100: Code-first aliases should contain only valid characters

| Property | Value |
| -------- | ----- |
| Id       | UCF100 |
| Category | CodeFirst |
| Severity | Error |
| Code fix | No |

## Example

### Code with Diagnostic

```csharp
[UCFContentType("product_page", "Product Page")]
public partial class ProductPage;
```

### Code without Diagnostic

```csharp
[UCFContentType("product-page", "Product Page")]
public partial class ProductPage;
```

## Remarks

Aliases may contain letters, combining marks, numbers, whitespace, periods, and hyphens. Other
characters can produce invalid or inconsistent Umbraco aliases.
