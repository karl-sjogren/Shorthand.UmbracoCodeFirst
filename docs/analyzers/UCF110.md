# UCF110: Incompatible content composition type

`UCFComposite` must compose the same kind of code-first type. An Element Type cannot compose a
Document Type, and a Document Type cannot compose an Element Type.

## Example

```csharp
[UCFElementType("shared")]
[UCFComposite(typeof(Document))]
public partial class SharedElement;

[UCFDocumentType("document")]
public partial class Document;
```

The `UCFComposite` declaration on `SharedElement` produces UCF110 because an Element Type cannot
compose a Document Type.

Use matching `UCFDocumentType` or `UCFElementType` attributes on the source and target types.
