# UCF106: Invalid content composition target

`UCFComposite` may only reference a class declared with `UCFDocumentAttribute` or
`UCFElementTypeAttribute`. The composing and composed types must have the same kind.

## Example

```csharp
[UCFDocument("product", "Product")]
[UCFComposite(typeof(NotADocumentType))]
public partial class Product;
```

Declare the referenced class as a matching code-first Document or Element Type, or remove the
composition.
