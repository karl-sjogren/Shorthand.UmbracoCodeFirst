# UCF102: Repeated layout configuration should use a shared attribute

| Property | Value |
| -------- | ----- |
| Id       | UCF102 |
| Category | CodeFirst |
| Severity | Warning |
| Code fix | No |

## Example

### Code with Diagnostic

```csharp
[UCFGroup("productDetails", "Product details")]
public partial string Name { get; }

[UCFGroup("productDetails", "Product details")]
public partial string Sku { get; }
```

### Code without Diagnostic

```csharp
[ProductDetailsGroup]
public partial string Name { get; }

[ProductDetailsGroup]
public partial string Sku { get; }
```

## Remarks

Define a derived `UCFGroupAttribute` or `UCFTabAttribute` once and reuse it when several
properties share the same layout configuration. This keeps names and sort orders consistent.
