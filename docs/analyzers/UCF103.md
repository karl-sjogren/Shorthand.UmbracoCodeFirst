# UCF103: Repeated validation configuration should use a shared attribute

| Property | Value |
| -------- | ----- |
| Id       | UCF103 |
| Category | CodeFirst |
| Severity | Information |
| Code fix | No |

## Example

### Code with Diagnostic

```csharp
[UCFValidation("^[A-Z]+$", "Uppercase only")]
public partial string Sku { get; }

[UCFValidation("^[A-Z]+$", "Uppercase only")]
public partial string ProductCode { get; }
```

### Code without Diagnostic

```csharp
[UppercaseCodeValidation]
public partial string Sku { get; }

[UppercaseCodeValidation]
public partial string ProductCode { get; }
```

## Remarks

Define a derived `UCFValidationAttribute` for validation rules reused by multiple properties. The
derived attribute can be updated in one place without duplicating expressions and messages.
