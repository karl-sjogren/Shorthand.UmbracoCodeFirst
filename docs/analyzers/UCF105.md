# UCF105: UCF properties should be declared on a content type

| Property | Value |
| -------- | ----- |
| Id       | UCF105 |
| Category | CodeFirst |
| Severity | Warning |
| Code fix | No |

## Example

### Code with Diagnostic

```csharp
public partial class Product
{
    [UCFProperty("name", "Name", "text")]
    public partial string Name { get; }
}
```

### Code without Diagnostic

```csharp
[UCFContentType("product", "Product")]
public partial class Product
{
    [UCFProperty("name", "Name", "text")]
    public partial string Name { get; }
}
```

## Remarks

`UCFProperty` metadata is interpreted as part of a generated Umbraco content type. Add
`UCFContentType` to the containing partial class so the generator has a definition to attach the
property to.
