# UCF104: UCF properties should use a supported CLR type

| Property | Value |
| -------- | ----- |
| Id       | UCF104 |
| Category | CodeFirst |
| Severity | Warning |
| Code fix | No |

## Example

### Code with Diagnostic

```csharp
[UCFDocumentType("product", "Product")]
public partial class Product
{
    [UCFProperty("value", "Value", "text")]
    public partial void Value { get; }
}
```

### Code without Diagnostic

```csharp
[UCFDocumentType("product", "Product")]
public partial class Product
{
    [UCFProperty("value", "Value", "text")]
    public partial string Value { get; }
}
```

## Remarks

The source generator cannot produce a published model property for pointer, function-pointer, or
`void` property types. Use a CLR type supported by the generated published model contract.
