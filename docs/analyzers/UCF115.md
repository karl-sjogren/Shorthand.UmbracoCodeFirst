# UCF115: Invalid collection configuration type

The type passed to `UCFCollection` must inherit from `CodeFirstCollectionConfiguration`.

```csharp
[UCFDocumentType("Blog")]
[UCFCollection(typeof(BlogCollection))]
public partial class Blog;

public sealed class BlogCollection : CodeFirstCollectionConfiguration;
```

The configuration must also be concrete and have a public parameterless constructor. The source
generator validates those requirements and whether the attribute is applied to a document or media
type.
