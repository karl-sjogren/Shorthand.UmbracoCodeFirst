# Umbraco CodeFirst

This package provides analyzers and source generators for Umbraco CodeFirst development.
It is kind of a mess right now.

This is so far more of a proof of concept and development might stall at any time so
don't use this in any serious production scenarios just yet.

## Packages

| Package | Description |
| --- | --- |
| [Shorthand.UmbracoCodeFirst](https://www.nuget.org/packages/Shorthand.UmbracoCodeFirst) | The main package for Umbraco CodeFirst development. |
| [Shorthand.UmbracoCodeFirst.Analyzers](https://www.nuget.org/packages/Shorthand.UmbracoCodeFirst.Analyzers) | Provides Roslyn analyzers for Umbraco CodeFirst development. |
| [Shorthand.UmbracoCodeFirst.Backoffice](https://www.nuget.org/packages/Shorthand.UmbracoCodeFirst.Backoffice) | Provides backoffice integration for Umbraco CodeFirst development. |
| [Shorthand.UmbracoCodeFirst.Core](https://www.nuget.org/packages/Shorthand.UmbracoCodeFirst.Core) | Provides core functionality for Umbraco CodeFirst development. |
| [Shorthand.UmbracoCodeFirst.SourceGenerators](https://www.nuget.org/packages/Shorthand.UmbracoCodeFirst.SourceGenerators) | Provides source generators for Umbraco CodeFirst development. |
